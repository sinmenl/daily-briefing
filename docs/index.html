第一步喝水、吃饭、洗漱后再决定能否工作

02

昨日记录把能力拆为“能否讲清楚、按时交付、解决具体问题、持续重复产生结果”等小问题。今天只选第一个：能否把一个刚理解的知识点讲给不了解的人听。写清一个对象、一个问题、一个例子和一句结论；不评判整个人，也不补更多方法。

第一步写下“我想让谁少在哪一步卡住”

03

先录音，不强制录像或发布。录完只回听一次，标记最难理解的一句话；有精力再修这一处。若能找到一位听者，只问是否听懂主张、哪句难懂、是否有一点实际帮助，不问人格评价。

第一步按“问题—例子—结论”说第一遍

01创作者平台Disney 与 TikTok 让授权 IP 进入创作者二次生产链路真实创作者、授权边界与平台分发共同构成一次内容实验。＋

事实与时间：TechRadar 在 2026 年 8 月 5 日 20:30 UTC（北京时间 8 月 6 日 04:30）报道，Disney 与 TikTok 的合作将让部分入选创作者使用 Disney 旗下 IP 创作内容；相关竖屏作品未来可能进入 Disney+ 的 Verts 标签。报道特别将这条路径和此前围绕 AI 生成 IP 内容的方案区分开来。

背景：传统娱乐公司的内容链路通常是“公司生产—平台分发—用户消费”。授权创作者参与后，IP 会先成为创作者的表达材料，再在真实平台上被用户观看、评论、分享和筛选。这里的“授权”不只是给素材，而是在规定可用边界、品牌责任和分发入口后，允许更多表达版本出现。

为什么重要：对 Disney 而言，创作者不只是在帮忙扩散广告；他们是低成本、真实语境中的内容实验网络。公司不必预先判断每一种角色解读、梗或叙事是否会获得反馈，而是能观察哪些版本真正引发参与。

产品与用户研究视角：用户既想消费熟悉 IP，也想看到角色如何进入当下情境、普通人如何参与和再解释。产品问题因此从“能否生成更多内容”变成“如何让用户在清晰授权与责任边界中参与，同时不损害原 IP 的信任”。

早报分析 / 建议：知识内容也可区分“世界观 / 可复用材料”和“最终答案”。例如一条 AI 知识视频可以提供一句概念、一个真实例子、一个反例和一个待回答的问题，邀请读者在自己的场景中补充。前提是清楚说明：哪部分是事实，哪部分是暂时解释，哪部分还需要验证。

适用边界：这不表示所有品牌都应开放二创。高度依赖安全、专业责任或角色一致性的领域，需要先定义授权范围、审核机制和错误成本；没有这些边界的“参与”很可能只会放大风险。

观察产品观察创作者平台真正要设计的是“参与的责任边界”授权、素材、身份与反馈，缺一项都不能形成健康的参与循环。＋

把用户变成创作者看起来像扩大供给，实际涉及四件不同的事：谁可以参与、能用什么材料、作品进入哪里、出错由谁负责。Disney 与 TikTok 的合作之所以值得看，不是因为它把用户内容当作免费库存，而是因为它把 IP、授权、审核和潜在的 Disney+ 分发放进了同一条链路。

这个框架也能用于看个人内容系统：素材库不是内容本身；只有当素材能被用来完成一次面向具体对象的表达、收到反馈并回流到下一次选择时，它才进入工作流。否则它只是更容易搜索的收藏夹。

适用边界：个人创作者没有大型 IP 的授权与审核资源，因此更需要保留来源、原始案例、判断边界和修改记录。参与不是让用户替你补齐观点，而是让你更快发现观点在哪个场景不成立。

之后录 60 秒。录完请一位不了解主题的人听，固定只问：他听到的主张是什么、哪一句不清楚、是否知道下一步。对方的回答是这一次内容的反馈数据，不是对个人能力的审判。

小报童 · 姜胡说 · 2026-07-20 14:20:07认真做好这件小事阅读导引：把“知道但做不到”缩小到一个可完成动作
原文
小报童原文

我翻了626条来自星球、小报童、抖音评论区的提问，发现：大部分人不是能力不行，也不是不努力。是卡在了：

三道关卡

第一道关卡：不知道拍什么 今天抄这个爆款，明天换那个方向。一年下来，拍了几十条视频，切换了四、五个人设；别说平台不认识你，你自己都不知道自己“应该是谁”。

“每天都在想选题，每天都很内耗自己不知道拍什么”

第二道关卡：知道但做不到 你听懂了，但懂和做之间隔了一道厚厚的墙，没法启动。

“每次看完你的作品就觉得拍视频特别简单，但一打开手机就不知道说什么，不敢露脸”

第三道关卡：“做了没结果” “该做的我都做了，但为什么没有结果？” 很多人把“装工具”当成“在进步”——装了一堆，一个都没用透。

“个人操作系统已经搭好了，但是不知道具体怎么落地创造实际的价值”

这三关是连在一起的：不知道拍什么 → 拖着不开始 → 越拖越焦虑 → 研究新工具 / 搭系统缓解焦虑 → 装了一堆还是没结果 → 更迷茫 → 更不知道拍什么。

这不是你的问题，是这个循环本身的设计——你越想“准备好再开始”，就越不会开始。

怎么破？

大多数人以为是：方向 → 行动 → 工具；但实际能走通的是：行动 → 方向 → 工具。

先动起来。方向在行动中浮现，在卡住时，你才知道该学什么知识，该用哪个工具。

但前提是——收收心。拍了10条视频就问为什么没流量，100个粉丝就想着怎么变现。路都走不稳，就想着御剑飞行。这可能才是你真正的问题。

不知道拍什么？

那就先不找方向，先锁定结构。

方向是抽象的。结构是具体的，先从能做的事做起。

四步结构：痛点 → 反常识 → 方案 → 金句。

  • 痛点：你最近被什么卡住了
  • 反常识：大多数人以为的解法为什么是错的
  • 方案：你的解法是什么，一两句话
  • 金句：一句话让前面所有内容被记住

前面加一个钩子——吸引。第一句话就得让人停下来。四步是内容，吸引是手段。

行动：今天写一条，200字，连写14天。14天后素材堆在那，你不需要问“我该拍什么”。

我就不举例子了，我80%以上的视频都是案例——简单的方法重复做。我们大部分老伙计的情况是：好的，我知道了。然后，为什么我的视频没流量？钱去哪儿领？知道和做到，是两回事。

知道但做不到，怎么办？

从小事做起。认认真真做好一件小事。

这是我们很多老伙计的问题。老想干大事。基本功不够，但有种想得跳跃，一步到位。这是好听的说法。不好听的说法就叫：好高骛远，急功近利。

结果呢？大事干不了，小事看不上。连“开始”都没做到。

脑子里想的一上来就搞个“大的”——打光、布景、写脚本、背稿、剪辑、发布。跟一上来就想跑马拉松一样。相信我，你跑不下来的。想像和实际是两回事。而最简单、有效的方法是：穿鞋下楼，走两圈。

拍视频也一样。别一上来就想拍得多好，允许自己录不好。先只录60秒；先只写第一句话；就用最普通的手机拍摄。先拍60秒，再拍2分钟；先能把话说清楚，然后再看怎么讲好、讲得精彩。别跳，你现在能做到什么就做什么。

先动起来，形成习惯。然后再慢慢优化。

做！去做！一边做一边学，而不是学完了再做。取得领先的秘诀是先开始。而开始的秘诀，就是把复杂的事分割成一件件做得到的小事，然后从第一件开始。

做了没结果，怎么办？

钉子优先，锤子后置。

你搭建系统、安装工具、学习方法，是从“我做了什么”出发。你做了什么，市场不关心。市场关心的是，你能为“我”做什么。

发现问题，解决问题。市场需要的不是你装了什么工具，是你解决了什么问题。

先把钉子钉在墙上，再去找锤子。

找出最近一个最烦的问题，把它描述清楚，越具体越好。然后只找一个能解决它的工具，把它做透。能解决就固化，不能就换下一个。不要偷工减料，不要奇技淫巧。

然后你就有了很好的结构：痛点 → 反常识 → 方案 → 金句。然后，前面再加上一点点——吸引。

你不需要更多工具，你需要更少的问题。

基本功不扎实，装再多工具也是花架子。

可惜很少有人静下心来，认认真真、踏踏实实地去完成这样一件小事。他们总是希望我快速拍一条视频，然后就爆了，然后我就有了大量的流量，再然后我就挣钱了。

结果就是，永远卡在那个地方，陷入无尽的焦虑，不停地找爆款，追热点……

为什么我知道？很简单——因为傻子都是这么做的。这是他们的共性。

写在结尾

卡在哪今天做什么
不知道拍什么，换了好几个方向都不对写一条四步结构
知道该拍什么，但每天拖着不开始从小事做起，先完成再优化
系统搭好了，方法学了不少，但就是没结果写一个最烦的问题，今天只解决它

没有什么新鲜内容，都是一些最简单的道理。需要做的就是静下心来，认认真真把这一件小事做好、做完整。

查理·芒格说：“人一辈子做对两件事情就可以很富有：寻找什么是有效的，重复它；发现什么是无效的，避免它。我们不需要新的思想，我们只需要正确的重复。”

昨日复盘

事实：8 月 6 日日记记录去游泳，因车没电到朋友家；两人讨论广西扶持、普通人就业与城市升级机会。之后记录了对一条短视频的反感、比较冲动与“能力如何被检验”的长段对话。

完成与未完成：日记有游泳、交流、问题拆解和完整记录；没有记录当天完成的视频、公开发布、用户测试或其他可确认的内容交付。没有把“没有视频成品”写成“什么都没做”。

情绪与精力信号：日记出现对资源无力感、对比较的觉察，以及担心能力被判定的描述。近周还有反复晚睡、补觉和运动不适的记录；这些都支持今天主动缩小计划。

需延续：把笼统问题拆成不同层次，例如“总就业需求是否增加”“谁能获得高质量岗位”“普通人能靠近哪些新增问题”，比用一个大结论盖住所有情况更有用。
